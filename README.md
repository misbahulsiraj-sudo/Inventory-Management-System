# 🧰 Inventory Management System

A simple and professional Inventory Management System developed using Python. This project helps manage products, stock quantities, prices, and basic sales operations through a menu-driven console interface.

## Features

- Add new products
- View all products 
- Search products
- Update product details
- Delete products
- Track stock quantity
- Low stock alerts
- Sell products
- Automatic stock updates
- Calculate total sale amount
- Input validation
- Object-Oriented Programming (OOP)

## Technologies Used

- Python
- Classes & Objects
- Dictionaries
- Functions
- Loops
- Conditional Statements
- Basic Data Handling

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python inventory_management.py
